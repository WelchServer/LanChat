# LanChat
A Local Area Network service that allows for basic no-nonsense message and file transfer over local public IPs.

V1.0:
  Install the zip, unpack, run LanChat.exe inside the folder.
  Enter Name (any name) and the IP address of the computer you would like to reach, that computer will need to do the same but with your IP address.
  It is worth it to note that the file transfer system is using IPAddress.Any which is a low security option. Future updates of LanChat will take security into consideration but it is currently a trusted peer-to-peer project not one to use on any public network.

  The theoretical file transfer limit of this application is roughly 9.2 Exabytes, so the real limit should remain your local network capabilities.
